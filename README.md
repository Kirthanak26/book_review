# Book Review Tracker

Book Review Tracker is a web application built with Flask and SQLAlchemy that allows users to manage and analyze book reviews.

## Features

- Add new book reviews
- View all saved reviews
- Edit existing reviews
- Delete reviews
- Filter reviews by book title and rating
- Generate custom reports
- Store review data in a SQLite database
- Responsive Bootstrap-based user interface

## Technologies Used

- Python
- Flask
- SQLAlchemy
- SQLite
- HTML
